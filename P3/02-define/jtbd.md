## Eight job stories
_When... I want to... so I can..._ [Hypothesis]

- When I realise I've been scammed, I want to know the first thing to do right now, so I don't waste the first hour.
- When I call 1930, I want the reporting number saved for me, so I don't lose it in the panic.
- When my bank asks what happened, I want my facts ready, so I don't repeat the story four times.
- When I'm told to 'keep evidence', I want my screenshots, messages and transaction ids gathered for me, so nothing is lost.
- When I've reported, I want one place that shows where each channel stands, so I'm not guessing.
- When I wait months, I want honest expectations of what can and can't happen, so I don't hope blindly.
- When I'm too shaken to do it, I want a family member to help with my permission, so I'm not alone.
- When it's over, I want to learn what to watch for, so it doesn't happen again.
