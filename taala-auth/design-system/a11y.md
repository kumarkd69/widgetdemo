# Accessibility (WCAG 2.2 AA)

## Rules
- Contrast: text ≥ 4.5:1, large text and graphics ≥ 3:1 (values in `tokens.json` → `contrast`).
- Targets ≥ 48×48dp (exceeds 2.5.8's 24px minimum); PIN keys 64dp.
- Status never by colour alone: Trust Meter uses icon + segments + label (1.4.1).
- Timing adjustable (2.2.1): every timer has "Need more time?"; timers pause while a screen reader is speaking a live region.
- No cognitive tests for auth (3.3.8 Accessible Authentication): no CAPTCHAs; paste and autofill allowed in OTP; password managers allowed on web.
- Focus order follows reading order; focus moves to the sheet title on open and back to the trigger on close.
- Reduced motion: no meter fill animation, no shake (use text + haptic).
- Text resize to 200% without loss; Auth Sheet scrolls.
- Every component works with switch access and an external keyboard.

## Screen-reader scripts (TalkBack / VoiceOver)
| Component | Announcement |
|---|---|
| Auth Sheet open | "Pay ₹450 to Sri Ganesh Stores. Sheet. Risk low: known payee, small amount." |
| Trust Meter | "Risk level: Medium, 2 of 4. First payment to this person. Double-tap for why." |
| Biometric Prompt | "Confirm with fingerprint. Or double-tap 'Try another way'." |
| Biometric fail | "Didn't match. Try again. 1 more try before other options." |
| PIN Pad key | "Digit entered, 3 of 6." (never speaks the digit) |
| PIN wrong | "Wrong PIN. 2 tries left. Forgot PIN, button." |
| OTP Input | "Code from SMS, 6 digits, edit box. Never share this code." |
| OTP autofill | "Code filled from SMS." |
| Cooldown Timer | "Paused until 9:42 PM. Reset PIN, button. Call us, button." |
| Step-up Explainer | "Extra check: new payee and a large amount." |
| Fallback Chooser | "Try another way. 3 options. Use UPI PIN, 1 of 3." |
| Lockout Card | "PIN paused for your safety until 9:42 PM. Reset PIN, button. Call us, button." |
| Success | "Paid ₹450 to Sri Ganesh Stores at 9:42 PM. Reference ending 4821." |
| Language Switcher | "Language: English, selected. हिन्दी. ಕನ್ನಡ." (each in its own locale) |
| Toast | Announced politely, not assertive, unless it's an error. |
