# Captions (decision, not pixels)

| Exhibit | Caption |
|---|---|
| Hero | One sheet, one meter, five products: the same risk looks the same everywhere. |
| RBI board | The rule sets a floor of two factors; everything above it is a design choice. |
| Inconsistency board | Six OTP screens teach users nothing, which is exactly what a phisher needs. |
| Personas | Designed for the person whose fingerprint fails, not the one whose never does. |
| Journey: Meena | A failed fingerprint should cost two seconds, not a lockout. |
| Journey: Arjun | Say the limit when the payee is added, not when the payment fails. |
| Journey: Priya | A dead Indian SIM shouldn't block a purchase abroad. |
| Tier summary | Four tiers, because analysts and users both need to hold the model in their heads. |
| Decision matrix | Every row proves two categories and one dynamic factor, or names its exemption. |
| Fallback ladder | Every arrow ends with a person. |
| Trust Meter | Colour, shape, count and words: risk readable four ways. |
| Auth Sheet | Fallbacks swap inside the sheet so users never lose their place. |
| PIN Pad | Screen readers hear "3 of 6", never the digit. |
| OTP Input | One field that looks like six boxes, so TalkBack reads it as one. |
| Cross-border approval | Push to the bound phone replaces an SMS that can't arrive. |
| Scam-call warning | A 30-second pause, framed as a question, not an accusation. |
| Net banking login | The `.bank.in` domain is shown because it's the cue users can check. |
| Policy console | Risk can see exactly what a user will see before changing a rule. |
| Roadmap | Pilot where volume is high and amounts are small. |
| Metrics tree | The north star is the legitimate user getting through first time. |
