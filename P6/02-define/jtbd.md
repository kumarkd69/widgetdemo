# P6 Sooner · Define (hypotheses from desk research; no interviews yet)

## Eight job stories
_When... I want to... so I can..._ [Hypothesis]

- When someone collapses, I want one tap to ask for help, so I don't waste time searching.
- When I pick an ambulance, I want a fixed or capped price upfront, so I'm not surprised.
- When I describe the problem, I want simple questions in plain words, so I get the right equipment without medical terms.
- When the ambulance is coming, I want to see where it is and when it arrives, so I can plan.
- When the crew arrives, I want to know they're qualified, so I trust them.
- When I'm in a bad signal area, I want it to still work, so I'm never stuck.
- When the trip ends, I want the bill checked against the quote, so I know I was treated fairly.
- When I run an ambulance, I want a fair price and prompt payment, so the work is viable.
