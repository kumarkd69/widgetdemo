# P5 Fineprint · Define (hypotheses from desk research; no interviews yet)

## Eight job stories
_When... I want to... so I can..._ [Hypothesis]

- When I need my first health cover, I want to start from my needs, so I'm not shown 40 products.
- When I look at a policy, I want to see what it does NOT cover first, so there are no surprises at claim time.
- When I compare two policies, I want honest trade-offs in plain words, so I can choose with confidence.
- When I imagine a hospital stay, I want to see what I'd pay out of pocket, so I can judge the policy.
- When a list is ranked, I want to know why, so I can trust it isn't paid for.
- When I already hold policies, I want gaps shown, so I buy only what I'm missing.
- When it's renewal time, I want a coach to tell me what changed, so I don't renew blindly.
- When I'm stuck, I want to talk to a licensed advisor, so a person can help.
