# P1 Rein · Define (hypotheses from desk research; no interviews yet)

## Eight job stories
_When... I want to... so I can..._ [Hypothesis]

- When I let an agent shop for me, I want to set what, how much and where, so I can sleep.
- When the agent pays, I want to see it at once with the reason, so I know it was right.
- When something looks off, I want to pause everything with one tap, so I limit the damage.
- When I'm unsure about a payment, I want to ask 'why did my agent pay this?', so I can decide to keep or stop the agent.
- When a payment is within limits but wrong, I want a clear way to dispute it, so I get my money back.
- When my mother's agent pays, I want to see it as her family helper, so I can step in without taking over.
- When I'm a bank officer, I want the agent's mandate, inputs and checks in one view, so I can judge the dispute.
- When I choose an agent, I want a trust badge from a real registry, so I don't trust a stranger.
