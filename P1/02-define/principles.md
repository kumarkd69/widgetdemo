# P1 Rein · Define (hypotheses from desk research; no interviews yet)

## Six design principles for Rein
_Used to judge every concept._ [Hypothesis]

**1 Limits before trust**
Start small; widen with evidence.

**2 Short why**
Show the request and the checks, not model thoughts.

**3 The model never authorises**
Rules do; Rein shows the rules.

**4 One tap to stop**
Pause and revoke are always at hand.

**5 Quiet by default**
Ask only when risk is real.

**6 Family-safe**
Helpers see, owners decide.
