# P4 Passline · Define (hypotheses from desk research; no interviews yet)

## Eight job stories
_When... I want to... so I can..._ [Hypothesis]

- When a toll payment fails, I want to know within minutes, so I can pay the normal fee.
- When I get an e-notice, I want to know it's genuine, so I don't fall for a fake SMS.
- When I see a notice, I want the photo, gantry and time, so I can tell if it's my car.
- When it's not my car, I want a guided dispute with the right evidence, so I win it inside 72 hours.
- When my son drives the car, I want him to see the alert too, so we fix it together.
- When I run a fleet, I want all notices by cab in one place, so nothing slips past 72 hours.
- When I buy a used car, I want to check unpaid tolls first, so I don't inherit a block.
- When a notice is settled, I want proof that it's closed, so the VAHAN record stays clean.
