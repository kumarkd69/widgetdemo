# P2 Nod · Define (hypotheses from desk research; no interviews yet)

## North Star, HEART, guardrails
_All baselines are 'to be measured'. Nothing here is a result._ [Hypothesis]

North Star: verified withdrawals per active user per quarter (withdrawal with a company 'stopped' receipt within 7 days). Target to set after baseline.

| HEART | Metric | Baseline |
|---|---|---|
| Happiness | Trust rating after a withdrawal (1-5) | To be measured |
| Engagement | Consents reviewed per user per month | To be measured |
| Adoption | Users who link 5+ apps in week 1 | To be measured |
| Retention | Users active at day 90 | To be measured |
| Task success | Withdrawals completed without help | To be measured |

| Guardrail | Why |
|---|---|
| Data stored by Nod beyond consent records = 0 | Data-blind rule |
| Nudges that push users to keep consent = 0 | Neutrality |
| Time to withdraw under 30 seconds | Equal ease |
| Support tickets per 1,000 users | Don't shift cost to help desk |
