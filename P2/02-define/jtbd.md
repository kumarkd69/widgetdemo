# P2 Nod · Define (hypotheses from desk research; no interviews yet)

## Eight job stories
_When... I want to... so I can..._ [Hypothesis]

- When I get a spam call right after signing up somewhere, I want to see which app has my number, so I can stop it.
- When a new app asks for consent, I want the purpose in plain words, so I can say yes or no without fear.
- When I no longer use an app, I want to withdraw consent in one tap, so I can be sure it stops.
- When I withdraw, I want proof the company stopped, so I don't have to trust and hope.
- When my child installs an app, I want to approve or refuse as the guardian, so their data is protected.
- When I think a company misused my data, I want to raise a grievance from the same place, so I don't hunt for a form.
- When I can't read English well, I want Hindi or Kannada and voice help, so I can decide on my own.
- When I'm a company privacy officer, I want consent records and withdrawals in one feed, so I can show compliance.
